    {Prototype Contactless Bitcoin Lightning Payments}}
      % Situation

        Lightning wallets lacked contactless payment capabilities available in traditional
        mobile payment systems.\\
      % Target
        Design and implement an NFC-based contactless payment solution for Bitcoin Lightning
        networks, requiring integration between hardware terminal and mobile wallet software.\\
      % Action
        Over 48 hours, I architected and implemented a full-stack solution: designed a payment
        requester terminal using Raspberry Pi with RC532 NFC breakout board, and extended the
        open-source zap-android wallet with NFC functionality.\\
      % Result
        Delivered working prototype demonstrating contactless Bitcoin Lightning payments, with
        NFC enhancement refined and merged into main zap-android project.\\
